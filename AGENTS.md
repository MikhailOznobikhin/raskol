# AGENTS.md — Инструкция и правила для ИИ-агентов

Читай этот файл перед отправкой любого кода или изменением файлов. 
Смежные инструкции: `ROADMAP.md` (архитектура, грабли) и `TASKS_AI.md` (формат задач).

---

## 1. Главные правила автономного агента

1. **Без заглушек и TODO:** Запрещено оставлять `# TODO`, `pass` в критических местах или недописанный код. Все функции должны быть скомпилируемыми и рабочими.
2. **Атомарность:** Одна задача — одна карточка из `TASKS_AI.md`. Разрешено править **только** файлы, указанные в описании задачи.
3. **Самостоятельная проверка:** Всегда самостоятельно перепроверяй типы и синтаксис GDScript перед запуском тестов.
4. **Формат коммита:** Один успешный прогон тестов = один атомарный коммит:
   `git commit -m "<ID_карточки>: <краткое описание на русском>"` (например, `T10: подключение AnimationTree для героя`).

---

## 2. Архитектура и стек проекта

- **Движок:** Godot **4.4.1** (Forward+ renderer).
- **Жанр:** 3D-RPG от третьего лица ("Раскол").
- **Главные точки входа:**
  - `main3d.tscn` → `scripts/main3d.gd` (главная сцена и менеджер состояния).
  - `scripts/hero3d.gd` — управление, анимации, боя и камера героя (Торвин).
  - `scripts/enemy3d.gd` — ИИ врагов, стелс (конус зрения, слух, патрули).
  - `scripts/dungeon.gd` — процедурная/блочная сборка уровня из `assets/level/m1.txt`.
  - `scripts/mission3d.gd` — триггеры, квесты, логика Миссии 1 ("Escape").
  - `scripts/balance.gd` — единый источник численного баланса (HP, урон, магия).
  - `scripts/save_system.gd` — сериализация сохранений.
  - `scripts/model_util.gd` — хелпер загрузки моделей, калибровки высот и поиска костей.

## 3. Среда выполнения (Windows Sandbox)

Не запускай команды Godot/Python вручную через глобальные пути. Используй преднастроенные переменные и скрипты:

- **Godot:** `tools\godot\Godot_v4.4.1-stable_win64_console.exe`
- **Python:** `%USERPROFILE%\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe`
- **Окружение:** Для запуска Godot в изоляции обязательны переменные:
  `$env:APPDATA = "<проект>\tools\appdata"`
  `$env:LOCALAPPDATA = "<проект>\tools\localappdata"`
- **Автоматизация:** Все запуски делать **исключительно** через `build.ps1`.

## 4. Обязательный Pipeline проверки (Validation Pipeline)

Перед завершением задачи выполни последовательно в PowerShell:

```powershell
.\build.ps1 -Import   # 1) Регистрация class_name и импорт новых ассетов (.glb, .wav)
.\build.ps1 -Test     # 2) Автотест: обязателен вывод "[OK] TEST: TEST DONE escaped=true"
.\build.ps1 -Shots    # 3) Генерация визуальных скриншотов в tools\shot_3d_*.png (для задач по visual/UI/geometry)
