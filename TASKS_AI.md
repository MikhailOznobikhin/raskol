# ЗАДАЧИ ДЛЯ ДРУГИХ НЕЙРОСЕТЕЙ

Готовые брифы для openrouter/free, Gemini и прочих. Скопируй блок задачи целиком
(вместе с §1 — он обязателен), добавь в конец «работай в C:\Users\mixao\myproject\game»
и отправь. Чем конкретнее файл/функция/критерий — тем меньше модель будет
переспрашивать.

> Почему твой прошлый промпт провалился: «улучши графику, сделай крутую модель»
> не содержит ни файла, ни функции, ни критерия приёмки. Модель не знает, что у
> нас 3D-риг из примитивов в `hero3d.gd`, и честно отказалась. Ниже — версия,
> которую невозможно понять неправильно.

### T9. Живые 3D-модели вместо кубов — **L, ✅ СДЕЛАНО**

**Цель:** заменить код-риги из примитивов настоящими glTF-моделями с анимациями.

**Результат (что теперь в проекте):**

  `assets/guard.glb` — Quaternius «Skeleton» (5 клипов),

  `assets/weapon_hammer.glb` / `weapon_sword.glb` — оружие Quaternius. Лицензия CC0,
  источники — в `assets/CREDITS.md`.
- `scripts/model_util.gd` (`class_name ModelUtil`) — единственная точка загрузки:
  `spawn(parent, path, height, yaw)`, `pick_anim`/`play_key` (поиск клипа по
  синонимам), `bone_attach` (крепление к кости с компенсацией масштаба),
  `apply_overlay` (вспышка при попадании).
- `hero3d.gd`: `_attach_model` / `_attach_weapon` / `_animate_model`; молот висит на
  `BoneAttachment3D` кости `Wrist.R`.
- `enemy3d.gd`: та же схема для стражи и босса, отдельные высоты полос HP.
- `balance.gd`: `HERO_MODEL_HEIGHT=1.42`, `GUARD_MODEL_HEIGHT=1.80`,
  `BOSS_MODEL_HEIGHT=2.30`.
- Отладочные режимы в `main3d.gd`: `-- --models` (витрина герой/страж/дракон),
  `-- --fit` (герой с трёх сторон + проверка поворота при беге).

**Грабли, уже собранные на этой задаче (не повторять):**

1. `MeshInstance3D.get_aabb()` у скиннованных мешей раздут масштабом костей —
   высоту брать из `ModelUtil.NATIVE_HEIGHT` (числа измерены `tools/measure_models.gd`).
2. Кости glTF приходят с масштабом ~100: без контр-скейла молот получается 117 м
   и накрывает камеру. Лечится в `ModelUtil.bone_attach` + `grip.scale = 1/scale`.
3. Модели смотрят в `+Z`, а риг героя — в `-Z`. Поворот по движению считается как
   `atan2(-dir.x, -dir.z)`, иначе персонаж бежит спиной вперёд.
4. Autoload-глобалы (`Sfx`, `Art`, `Settings`) не видны в `--script`-режиме:
   витрины моделей запускать только через главную сцену (`-- --models`).

**Проверка:** `--import`, `--test3d` (`TEST DONE escaped=true`), `--shots`,
`-- --models`, `-- --fit`, `python tools/check_models.py`.

| Модель | Что получается | Что не давать |

| `google` / `gemini-3-flash-preview` | тексты, дизайн-доки, задачи до ~50 строк кода | большие правки в нескольких файлах |

(`--headless -- --test3d`), иначе модель упадёт в `null`.
